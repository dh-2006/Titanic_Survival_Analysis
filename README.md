# 🚢 Titanic Survival Analysis

### Exploratory Data Analysis (EDA) Using Python

## 📌 Project Overview

Titanic Survival Analysis is a Data Analytics project that explores the factors affecting passenger survival during the Titanic disaster.

This project performs Exploratory Data Analysis (EDA) using Python to understand survival patterns based on passenger class, gender, age, and ticket fare.

It uses Pandas and NumPy for data processing and numerical analysis, while Matplotlib and Seaborn are used to create meaningful visualizations.

## 📂 Dataset Information

**Dataset Name:** Titanic Dataset

**Source:** Kaggle – Titanic: Machine Learning from Disaster

**File Name:** `Titanic_Dataset.csv`

- Total Records: 891
- Total Columns: 12
- Target Variable: `Survived`

**Important Dataset Columns:**

- `Survived` – Survival status (0 = Not Survived, 1 = Survived)
- `Pclass` – Passenger Class
- `Sex` – Gender
- `Age` – Passenger Age
- `Fare` – Ticket Fare
- `Embarked` – Port of Embarkation

## ⚙️ Project Workflow

The project follows these steps:

**1. Data Collection**
- Download the Titanic dataset from Kaggle.
- Load the CSV file using Pandas.

**2. Data Exploration**
- Display the first five records.
- Check dataset shape and information.
- Identify missing values.

**3. Data Cleaning**
- Handle missing Age values using median.
- Handle missing Embarked values using mode.
- Check missing values after cleaning.

**4. Numerical Analysis Using NumPy**
- Calculate mean, median, and standard deviation.
- Find minimum and maximum ticket fares.
- Calculate percentiles and variance.
- Perform array operations using NumPy.

**5. Exploratory Data Analysis**
- Calculate total passengers and survival rate.
- Analyze survival by gender.
- Analyze survival by passenger class.
- Study survival by age groups.

**6. Data Visualization**
- Create different charts using Matplotlib and Seaborn.
- Understand survival patterns through graphs.

**7. Final Output**
- Display analysis results.
- Save all generated charts as PNG images.

## 📊 Visualizations

The project creates the following six visualizations:

| No. | Chart Name | Description |
|---|---|---|
| 1 | Survival Count | Shows survived and not-survived passengers |
| 2 | Survival by Gender | Compares survival between male and female passengers |
| 3 | Survival by Passenger Class | Shows survival count across passenger classes |
| 4 | Age Distribution | Displays the age distribution of passengers |
| 5 | Survival by Age Group | Compares survival rates across age groups |
| 6 | Fare by Passenger Class | Shows ticket fare distribution across classes |
